# 📦 VPS Backup Sync 使用指南与架构文档

**VPS Backup Sync** 是一款专为 Linux 云服务器与独立服务器设计的轻量级、零依赖数据备份与异地容灾同步工具。通过原生 Shell 脚本结合 `rsync` 与 `tar`，帮助运维人员与个人站长以极低的系统开销实现生产环境数据的安全归档与跨服务器迁移。

---

## 🌟 核心特性

- 🗄️ **全栈自动打包**：自动化扫描并备份网站根目录（如 `/var/www/html`）及 MySQL、MariaDB、PostgreSQL 数据库。
- 🚀 **断点续传与增量同步**：深度结合 SSH 隧道与 `rsync`（`--partial --inplace` 算法），应对跨国网络偶发断流，无需重新下载。
- 🔒 **数据完整性校验**：自动生成每个归档文件的 `SHA256` 校验和，确保跨机房传输无损。
- 🔄 **服务器间直连迁移**：源端 VPS 直传目标端 VPS，无需借助本地 PC 中转，节约海量本地带宽。
- ⏰ **定时备份与智能轮转**：内置自动化 Crontab 任务配置，搭配 7 天自动轮转清理逻辑，防止备份占满云盘。
